8-Stage Processing Stages

1. Data Ingestion

5,000 synthetic haul truck records across 5 core telemetry dimensions (Fog, LiDAR, Speed, Incline, Radar).

2. Physics Friction

Computes $\mu$ road friction degradation and safe stopping distance ($d_{safe} = v^2/2a_{eff} + v \cdot t_{react}$).

3. Hazard Zoning

Unsupervised clustering segments 3 risk zones: Optimal (Green), Caution (Yellow), and Critical (Red).

4. Scaling & Splitting

80/20 train/test split with zero-data-leakage standard scaling ($\mu=0, \sigma=1$).

5. Dual Baseline ML

Multiple Linear Regression (Continuous Distance) + Logistic Regression (Binary Collision Risk).

6. Deep Learning ANN

Keras 4-layer sequential network with Dropout regularization to capture non-linear brake dynamics.

7. Evaluation & Recall

Prioritizes Safety Recall (94.8%) over raw accuracy to eliminate catastrophic false negatives.

8. Dispatch Sandbox

Real-time edge prediction, dynamic alert cards, and target speed remediation.

Three-Tier Architectural Decomposition

1. Multi-Sensor Data Tier

Captures edge telemetry via optical transmissometers, 3D LiDAR scanners, velocity odometry, inclinometers, and front-facing radar. Coupled to the Newtonian friction and stopping distance physics digital-twin.

2. AI & Deep Learning Tier

Executes unsupervised Agglomerative/K-Means hazard clustering, dual linear/logistic baseline regression, and the deep Keras/TensorFlow multi-layer perceptron with Adam optimization for high-recall safety inference.

3. Edge Web & Dispatch Tier

Production Flask backend with sub-10ms REST inference (`/api/predict`), responsive dark industrial Tailwind UI, interactive 3D WebGL charts, and real-time collision micro-braking warning triggers.
